# Scentience Olfaction

Install the core Python package in the Isaac interpreter with `pip install -e .`
from the repository root. Enabling this extension verifies the core is available
and records its version in the Kit log. Simulation is configured through Python;
this extension does not create a scene or advance a plume on a wall-clock timer.

For robot mounting, plume configuration, sensor models and examples, see the
[repository documentation](https://github.com/Scentience/scentience-isaacsim#readme).
Isaac Lab 3 / Isaac Sim 6 is the target. Runtime components and robot assets
retain their own licensing terms.
